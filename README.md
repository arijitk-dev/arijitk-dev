# 🔥 Featured Projects

## ⚡ Real-Time Traffic Analytics Pipeline

Real-time streaming analytics pipeline built around **Kafka + Spark Structured Streaming + PostgreSQL + Grafana**.

### Architecture

```text
Event Producer
      ↓
    Kafka
      ↓
Spark Structured Streaming
      ↓
  PostgreSQL
      ↓
   Grafana
```

### Highlights

* Real-time event processing
* Event-time windowing
* Watermarking
* Streaming aggregations
* Dockerized infrastructure
* Real-time monitoring dashboard

🔗 [View Repository](https://github.com/arijitk-dev/Realtime_Traffic_Streaming_Monitoring)

---

## 🚕 Car Booking Application

A backend system for a ride-hailing platform built using **Spring Boot, PostgreSQL/PostGIS and AWS**.

### Highlights

* JWT authentication & authorization
* Driver onboarding
* Location-based driver matching
* PostGIS spatial queries
* Dynamic & surge pricing
* OSRM route calculation
* AWS deployment
* CI/CD pipeline

🔗 [View Repository](https://github.com/arijitk-dev/CarBookingApplication)
